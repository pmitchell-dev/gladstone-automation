🚀 OPENCLAW RPi5 COMMAND CENTER - QUICK REFERENCE
==========================================================

🔧 SYSTEM COMMANDS:
----------------------------------------------------------
cycle    - Restarts the OpenClaw Gateway service.
check    - Runs the Health Check (Service/Port/Logs).
printer  - Refreshes the Brother printer HTML data.
alert    - Manually triggers the Watchdog/Network check.
guide    - Displays this custom dashboard.

📂 FILE PATHS:
----------------------------------------------------------
Config   - ~/.openclaw/openclaw.json
Logs     - /tmp/openclaw/
Work     - ~/.openclaw/workspace/printer_status.html

🤖 TELEGRAM BOT CAPABILITIES:
----------------------------------------------------------
"Read printer_status.html" - Analyzes toner levels.
"D&D Stats..."             - Tracks your campaign.
