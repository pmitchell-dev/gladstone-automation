Master Script & Automation Index

install.sh
Setup
Universal bootstrap installer. Configures node role, installs dependencies & Docker, sets crontabs, and registers aliases.
backup_manager.py
Backup
Master Python backup engine. Generates compressed archives, computes SHA256 hashes, syncs to SMB share, and enforces 7-day retention.
pi_services_manager.sh
Watchdog
5-Strike Watchdog script. Checks process health every 5 minutes, performs 4 silent restarts, and dispatches Priority 5 ntfy alerts on 5th strike.
ntfy_listener.sh
Listener
Background daemon on Hub listening for remote commands from ntfy pub/sub topics to trigger local automation routines.
get_printer_status.sh
Scraper
Scrapes HTML telemetry from local Brother Network Printer every 4 hours, logging toner levels and page counts to ~/printer_data/.
net_speed.sh
Network
Audits network download/upload speeds and ping latency every 6 hours via speedtest-cli, sending warnings if bandwidth drops.
nvr_syslog.py
Syslog
Python UDP server on port 514 capturing camera events from ANNKE NVR system and streaming alerts into Dozzle.
gemini_api_server.py
AI API
FastAPI microservice offering AI endpoints on port 5050 powered by Google Gemini model integration.
pi-dashboard.sh
CLI UI
Rich terminal dashboard ('db') displaying RPi5 vitals, printer toner levels, speedtest history, and active log streams.
